# 博客侧边栏状态栏功能说明

## 功能概述
已为您的博客添加了右侧状态栏导航功能，提供快速的文章分类浏览和跳转。

## 已实现的功能

### 1. 右侧状态栏
- 位置：固定在页面右侧，垂直居中
- 样式：毛玻璃背景，圆角设计，悬停效果
- 内容：按文章分类组织，显示文章标题

### 2. 主要特性
- **分类组织**：自动识别文章分类（CTF、Kali、取证等）
- **折叠展开**：点击分类标题可折叠/展开文章列表
- **快速跳转**：点击文章标题平滑滚动到对应位置
- **高亮指示**：滚动时自动高亮当前阅读的文章
- **响应式设计**：移动端自动隐藏，提供切换按钮

### 3. 键盘快捷键
- `Ctrl + Shift + S`：显示/隐藏状态栏
- `ESC`：移动端隐藏状态栏

### 4. 主题优化
- 启用了 NexT 主题的 TOC 展开所有功能
- 优化了侧边栏 TOC 的粘性定位和滚动体验
- 添加了 TOC 链接的悬停效果

## 使用说明

### 桌面端
- 右侧状态栏默认显示
- 点击分类标题折叠/展开文章列表
- 点击文章标题跳转到对应位置
- 滚动时自动高亮当前阅读的文章

### 移动端
- 右下角显示切换按钮（📚）
- 点击按钮显示/隐藏状态栏
- 状态栏显示在屏幕上方

## 自定义配置

如需调整样式，可编辑以下文件：

1. **状态栏位置和大小**：修改 `sidebar-state.css` 中的 `.sidebar-state-container`
2. **颜色主题**：修改 CSS 中的颜色变量
3. **响应式断点**：修改 `@media (max-width: 768px)` 中的值

## 注意事项

1. 状态栏依赖文章页面的 DOM 结构，确保文章有正确的标题和链接
2. 分类识别基于 URL 路径和标签，如需调整可修改 JS 中的分类逻辑
3. 如果使用其他主题，可能需要调整样式兼容性

## 测试建议
