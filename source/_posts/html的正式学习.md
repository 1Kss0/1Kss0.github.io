# html的正式学习

快捷键：英文 !+tab ,生成html骨架

保存：ctrl+s保存，未保存时标题右边会有一个小白点

快速跳转到网页：Alt+l   +   Alt+o  ,使用前记得查看有没有保存

注释：ctrl+/    添加/取消注释

## 标签：

需要确定开始结束使用双标签，不需要开始结束使用单标签

标签关系：嵌套关系和并列关系

标题标签：<h1>一级标题</h1>总共只有6级

段落标签：<p>段落</p>

#### 换行标签:   

#### 水平分割线：<hr>

**文本格式化标签：**

|  标签   |  说明  |       标签        |  说明  |
| :-----: | :----: | :---------------: | :----: |
| <b></b> |  加粗  | <strong></strong> |  加粗  |
| <u></u> | 下划线 |    <ins></ins>    | 下划线 |
| <i></i> |  倾斜  |     <em></em>     |  倾斜  |
| <s></s> | 删除线 |    <del></del>    | 删除线 |

两者之间效果没有区别，只是在代码中更显眼，有强调作用

###### 媒体标签

图片标签：

每种属性之间用空格隔开。

arc后写图片的地址，alt是图片无法加载时显示的文本内容，不是必须填写。

title是鼠标悬停在图片上时显示的文字,若只定义width或height图片就会等比例缩放

##### 路径：

绝对路径：从盘符开始，如D:\pctf或者网址https://www.xxx，但是如果其他用户电脑内没有该文件的话就打不开，所以不会使用它

相对路径（常用）：从当前文件(当前的html文件)到目标文件

同级别目录：![](xxx.png)** **![](./xxx.png)

下级别目录：从当前html文件开始 （装目标图片的文件夹）/目标图片

上级别目录：先返回到上一级  "../"(返回上一级)+打开文件  例如![](../images/map.jpg)

##### 音频：

**代码****<audio src="./music.mp3" controls>****</audio>**

|  属性名  |             功能             |
| :------: | :--------------------------: |
|   src    |          音频的路径          |
| controls |        显示播放的控件        |
| autoplay | 自动播放（部分浏览器不支持） |
|   loop   |           循环播放           |

属性之间要打一个空格

**视频标签**：

代码：<video src="./video.mp4" controls loop autoplay></video>

|  属性名  |                      功能                       |
| :------: | :---------------------------------------------: |
|   src    |                   视频的路径                    |
| controls |                 显示播放的控件                  |
| autoplay | 自动播放（谷歌浏览器需要配合muted实现静音播放） |
|   loop   |                    循环播放                     |

属性之间要打一个空格

**链接标签：**

代码：右边这个应该是英文括号《/a> （打正确的代码他会缩在一起）  注意是href

或者目标网页《/a>

如果暂时不知道跳转的网站的网址可以先打一个“#”代表空链接以后再改

属性名：target=""

|  取值  |                  效果                  |
| :----: | :------------------------------------: |
| _self  | 默认值，在当前窗口中跳转（覆盖原网页） |
| _blank |      在新窗口中跳转（保留原网页）      |
